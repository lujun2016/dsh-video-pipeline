# 踩过的坑（按出现频率排序）

## 1. 逐帧不可复现：CSS 动画是元凶
CSS transition/animation 由浏览器时钟驱动，`__seek(t)` 无法控制。
**对策**：所有位移、透明度、缩放都由 t 计算，写完检查页面里没有 `transition:` 和
`@keyframes`。

## 2. Playwright 的 ESM/CJS 与路径坑
`NODE_PATH` 对 ESM import 无效；脚本用 CJS `require('playwright')`，或在项目里
`npm i -D playwright`。
**对策**：`render.cjs` 用 CJS；没装依赖时软链到全局包。

## 3. file:// 下不能 fetch 本地 JSON
截图页面用 `file://` 打开时，fetch 本地 JSON 会被拦。
**对策**：数据写成 `window.DATA = {...}` 的 JS 文件，用 `<script src>` 引入。

## 4. 竖屏底部 360px 会被平台 UI 挡住
抖音/视频号的文案、账号、按钮压在底部。
**对策**：注解最高只放到 y=1560（1080×1920 坐标系）。

## 5. 长文本溢出与重叠
日期行、两行注释、圆环与数字，最容易叠。
**对策**：抽 8–12 个关键时间点截图逐张看；宁可缩短文案，不要缩字号。

## 6. 图片放大裁切很难对准
按比例猜坐标，次次偏。
**对策**：放弃"放大镜"，改成「原图红框标出 + 右侧图例」，信息更清楚。

## 7. 渲染成本与磁盘
约 0.16 秒/帧；170 秒 @30fps = 5100 帧 ≈ 14 分钟；帧目录约 2.5–3 GB。
**对策**：渲染前清空 frames/；渲染完立即编码并删帧。

## 8. 字体
macOS 用 PingFang SC 即可；不要引 CDN 字体（渲染时可能拉不到）。
**对策**：`font-family: "PingFang SC","Hiragino Sans GB",sans-serif`。

## 9. 中文换行与标点
长句在窄容器里容易出现"孤字"（最后一行只剩一个字）。
**对策**：把文案改短，或在文案里主动断句。

## 10. 先文本稿，后画面
直接做画面容易返工。
**对策**：分镜文本稿先给用户逐行确认，再写代码。
