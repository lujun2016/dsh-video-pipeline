# 3D 镜头（three.js，可选但建议适当增多）

## 什么时候用

- **概念图 / 关系图**：节点在 3D 空间里分布，镜头缓慢推近
- **粒子场 / 数据流**：有纵深的流动
- **转场**：镜头穿过一层点云切到下一镜
- **不要用在**：文字多的镜头（中文排版交给 DOM，见下）

一条 2–3 分钟的片子，建议 **2–3 个**镜头用 3D，其余保持 2D。

## 与时间轴集成

- 场景在 `init()` 里建一次；`window.__seek(t)` 里只改相机 / 材质 / 实例矩阵，然后
  `renderer.render(scene, camera)`
- **禁止 `requestAnimationFrame`** 驱动动画；所有状态由 t 算出
- 随机分布用固定种子，保证每次渲染一致

## 文字

- 中文一律用 **DOM 覆盖层**，不用 `TextGeometry`
- 3D 里只放形状、线条、粒子；文字层用 CSS 定位

## 性能（1080×1920 / 30 fps）

- draw call < 200；粒子用 `InstancedMesh`
- 关闭 antialias，改用 FXAA 或直接不抗锯齿
- 纹理 ≤ 2048，避免每帧上传

## 模板里的示例

- `template/three-demo.html`：粒子云 + 关系线的 3D 场景，`window.__seek(t)` 驱动
- `template/render-3d.cjs`：起本地静态服务器（ESM 不能从 file:// 加载）→ Playwright 逐帧截图
- 命令：`npm run render:3d -- --seconds 5`

## 降级

WebGL 不可用时回退 Canvas 2D 版本，保证能出片。
