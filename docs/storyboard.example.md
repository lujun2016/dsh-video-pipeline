# 分镜文本稿格式示例

每一镜写四样东西：时间、画面上的每一行字、动画方式、上一镜产物如何进入本镜。

---

## 镜 1 · 0–9 秒 · 开场
画面文字：
- {{主标题}}
- {{副标题}}
- {{一句承诺：这条视频只跟一个概念走：X}}
动画：封面淡入并缓慢推近；标题三行依次升起；注解最后浮现。
承接：无（开场）。

## 镜 2 · 9–28 秒 · 原料
画面文字：
- 步骤 01 / N · {{步骤名}}
- {{一句结论：原料长什么样}}
- {{例子：一段真实文本 / 一张真实图片}}
- {{提取时的三个毛病，各一行}}
动画：页面图淡入；右侧文本逐字出现；三个毛病依次滑入。
承接：上一镜的"概念"第一次出现在原料里。

## 镜 3 · 28–52 秒 · 切分
画面文字：
- 步骤 02 / N · {{步骤名}}
- {{一句结论：把什么切成什么}}
- {{原文面板}}
- {{4 张句子卡}}
- {{被丢掉的部分}}
- {{产物的 JSON}}
动画：原文先整段出现 → 拆成句子卡 → 丢掉的部分滑出 → JSON 卡片浮现。
承接：原料文本 → 句子 → 单元。
